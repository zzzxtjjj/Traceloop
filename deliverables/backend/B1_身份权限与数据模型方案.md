        text | system | attachment\ncontent                 bounded text\nreply_to_id             nullable self FK, same project only\nclient_request_id       required idempotency key, unique per project + sender\ncreated_at\nupdated_at\n```\n\n索引：`(project_id, created_at, id)`、`(project_id, sender_id, client_request_id)` 唯一。分页使用 `(created_at, id)` 游标，不使用 offset 作为稳定同步依据。\n\n### Artifact 增量字段\n\n```text\nuploader_id             FK User\nmime_type               normalized declared type\nfile_size               bounded integer\nuploaded_at\nfile_hash               SHA-256\nversion                 integer\nparent_artifact_id      nullable self FK, same project only\nparsing_status          pending | parsed | failed | unsupported\nstorage_location        project-relative opaque path\n```\n\n不得删除现有字段。真实文件只存在受控 `data/uploads/<project_id>/`，数据库只保存元数据和相对定位；下载必须重新校验项目成员和文件归属。\n\n### DocumentExtraction\n\n```text\nid\nproject_id\nartifact_id             same project\nparser_name\nparser_version\nstatus                  pending | succeeded | failed | unsupported\ncontent_hash\ntext_excerpt / payload reference\nlocator_json            page, paragraph, sheet, row or line\nerror_code               sanitized, nullable\ncreated_at\n```\n\n原件永不被解析结果覆盖。扫描件、图片和不支持格式必须返回明确的 `unsupported`，不能伪造文本。\n\n### ExtractedRequirement\n\n```text\nid\nproject_id\nartifact_id\nextraction_id\nstatement\nrequirement_type\nowner_role\nacceptance_criteria_json\nsource_locator_json      must point to
