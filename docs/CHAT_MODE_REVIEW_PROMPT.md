## 七、两条工作流的证据核对

### 工作流 A：报价风险到任务验收

核对是否有证据支持以下完整链路：

```text
报价导入 → 字段/币种校验 → 原始字段 Evidence → 风险 Finding
→ 人工确认 → 任务草稿/发布 → 交付物 → 不同人工审核者验收
```

至少检查：正常报价、缺字段、混合币种、缺失信息、不自动编造和缺少交付物不能完成。

### 工作流 B：差评到改进复检

核对是否有证据支持以下完整链路：

```text
评价导入/去重 → 确定性统计 → 原文 Evidence → 原因假设
→ 人工接受/修改/驳回 → 改进任务 → 交付验收 → 下一批同口径复检
```

至少检查：重复评价、包装破损但无批次、供应商关联证据不足、样本量变化、非因果限制和缺失关系显示。

不要因为存在单元测试就自动认定页面工作流已被人工走通；要明确区分代码测试、页面 smoke 和现场人工验收。
