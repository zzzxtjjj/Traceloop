# 模型 API 本地配置与安全检查

TradeLoop 在没有模型配置时会继续使用可复现的规则分类。填写配置只代表应用已读取到参数，**不代表真实 API 已联网验证**，也不代表模型输出已经通过业务验收。

## 1. 仅在本机或部署平台保存密钥

本地开发时，先在项目根目录复制配置示例：

```powershell
Copy-Item .env.example .env
```

然后编辑 `.env`，使用占位符替换为你自己的值：

```dotenv
MODEL_API_KEY=<YOUR_API_KEY>
MODEL_NAME=<YOUR_MODEL_NAME>
MODEL_BASE_URL=https://api.openai.com/v1
MODEL_TIMEOUT_SECONDS=30
MODEL_MAX_INPUT_CHARS=50000
MODEL_MAX_REVIEWS_PER_RUN=200
MODEL_MAX_ATTEMPTS=1
```

- 密钥只放在本机 `.env` 或部署平台的 Secret 管理中。
- 不要把真实密钥提交到 Git、写进源代码、聊天记录、演示材料或截图。
- 不要把 `.env` 发给队友；应让每位开发者分别配置自己的本地环境。
- 页面只显示“已配置/未配置”，不会显示密钥内容。

`MODEL_MAX_ATTEMPTS` 默认是 `1`，不会自动进行结构修复重试。只有用户明确设置为 `2` 时，业务分析才允许在首个结构无效响应后进行一次修复请求。联网检查命令即使带 `--live` 也始终只发送一次最小请求，不使用这个重试额度。

`MODEL_BASE_URL` 可填写 OpenAI 兼容 API 的根地址。例如 `https://api.openai.com/v1` 是一种兼容地址写法；本文档列出的地址仅为配置示例，不代表当前环境已经联网或验证成功。具体模型名、权限、计费和数据处理规则应以所使用服务商的官方说明为准。

## 2. 先做离线安全检查

在项目根目录执行：

```powershell
python scripts\check_model_api.py
```

此命令只检查配置是否齐全、地址格式和本地安全状态，不应发起外部请求，也不会验证余额、模型权限或网络连通性。

修改 `.env` 后应停止并重新启动 Streamlit，让应用重新读取环境变量。重启后仍应先运行上面的离线检查，确认配置完整且格式有效。

## 3. 明确授权后再做真实联网检查

只有离线检查通过后，才考虑真实联网检查。真实联网检查可能产生请求、日志或费用；确认密钥归属、服务商地址、数据政策和预算后，再由操作者主动执行：

```powershell
python scripts\check_model_api.py --live
```

页面不会提供在线测试按钮，避免误触计费。联网检查完成后也只能说明当时的连接状态；业务页面中的模型输出仍必须经过结构校验和人工审核。

## 4. 最小化输入与排错

- 只发送完成当前分类所需的评价字段，避免发送姓名、电话、地址等无关个人信息。
- 如果页面显示“未配置”，检查 `.env` 是否位于项目根目录，以及 `MODEL_API_KEY`、`MODEL_NAME` 是否为空。
- 如果页面显示“尚未真实联网验证”，这属于安全默认状态；需要人工运行 `--live` 检查才能验证连接。
- 鉴权、超时、限流、服务端错误或坏结构不会被当作成功结果写入关键业务状态；系统会保留评价批次并提示规则降级。
